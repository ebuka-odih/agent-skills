# SEO glossary (the terms people ask about)

| Term | Meaning | Where it's handled |
|---|---|---|
| Crawling / indexing / ranking | fetching a URL / storing it as eligible / ordering it for a query — three different failures | site-audit / urls-and-indexing / keyword-research |
| Crawl budget | how many URLs a bot fetches; matters for 10k+ URL sites | sitemaps, no infinite params |
| Canonical | the one URL you want indexed among duplicates | on-page |
| noindex / nofollow | keep out of results / don't pass link signals | urls-and-indexing |
| robots.txt | crawl rules, not index rules | urls-and-indexing |
| Sitemap | list of indexable canonical URLs + lastmod | urls-and-indexing |
| SERP | search engine results page | — |
| SERP features | rich results, local pack, People Also Ask, AI Overviews | structured-data |
| Rich results | enhanced listings from structured data | structured-data |
| Search intent | what the searcher wants (informational, local, commercial, transactional, navigational) | keyword-research |
| Long-tail keyword | specific, lower-volume, higher-intent query | keyword-research |
| Striking distance | queries at positions ~4–20 — fastest wins | search-console |
| Impressions / clicks / CTR / average position | Search Console metrics | search-console |
| Keyword cannibalization | several of your URLs compete for one query | keyword-research |
| Core Web Vitals | LCP, INP, CLS at p75 of real users | page-speed |
| CrUX | Chrome UX Report, the field data behind CWV | page-speed |
| TTFB | time to first byte | page-speed |
| SSR / SSG / CSR | server / static / client rendering | rendering |
| Hydration | JS attaching to server HTML | rendering |
| hreflang / x-default | language-region alternates | international |
| E-E-A-T | experience, expertise, authoritativeness, trust — quality-rater concept, shown through real authorship, sources, contact info | on-page |
| Backlinks / anchor text / internal links | links from other sites / link text / links within your site | on-page (internal); off-page is out of scope |
| Thin content | pages with little unique value | programmatic-seo |
| Soft 404 | page returns 200 but says "not found"/is empty | site-audit |
| 301 / 302 / 410 | permanent / temporary / gone | urls-and-indexing |
| Programmatic SEO | pages generated from data at scale | programmatic-seo |
| Local SEO / NAP | local pack ranking / consistent name-address-phone | structured-data, Google Business Profile |
| Search Console / URL Inspection | Google's site tool / per-URL index status and live test | search-console |
