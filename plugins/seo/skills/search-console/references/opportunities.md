# Opportunities from Search Console

| Signal | Threshold (defaults in gsc-report.sh) | Action |
|---|---|---|
| Striking distance | avg position 4–20, impressions ≥ 50 | make the target page the best answer: phrase in title/h1, add the missing facts/sections, internal links from strong pages with the phrase as anchor |
| Low CTR for position | CTR < half the benchmark for its position, impressions ≥ 50 | rewrite title (specific, number, location, freshness) and description; earn rich results (`structured-data`) |
| Query with no matching page | page in results isn't about the query | new page or section (`keyword-research` → `programmatic-seo`) |
| Page with impressions, ~0 clicks | many queries at pos > 20 | consolidate or improve; check intent match |
| Branded query not #1 | brand name avg position > 1.5 | Organization/WebSite JSON-LD, clear home title, consistent name across profiles |
