# Conventional Commits

```
<type>(<scope>)<!>: <summary>

<body: why, and what changed that the diff doesn't make obvious>

<footers: Refs: T7, R7 · BREAKING CHANGE: … · Co-Authored-By: …>
```

## Types
| Type | Use for | Version bump |
|---|---|---|
| `feat` | new behavior | minor |
| `fix` | bug fix | patch |
| `perf` | faster, same behavior | patch |
| `refactor` | restructure, same behavior | — |
| `test` | tests only | — |
| `docs` | docs only | — |
| `build` | deps, build system | — |
| `ci` | CI config | — |
| `chore` | tooling, housekeeping | — |
| `revert` | `revert: <original subject>` + `This reverts commit <sha>.` | — |

`!` after type/scope or a `BREAKING CHANGE:` footer → major.

## Scope
The module/area from ARCHITECTURE.md (`bookings`, `auth`, `ai`, `api`) or the plugin/package. Optional; keep it short.

## Summary
| Bad | Good |
|---|---|
| `update code` | `fix(auth): reject expired refresh tokens` |
| `Added new feature for users.` | `feat(search): show open-now filter on results` |
| `fix bug` | `fix(payments): stop double-charging on webhook retry` |
| `WIP` | (don't commit WIP to shared branches; squash before PR) |

## Regex the hook checks
`^(feat|fix|perf|refactor|test|docs|build|ci|chore|revert|style)(\([a-z0-9._/-]+\))?!?: .{1,72}$` on the first line. Merge and revert commits generated by git are allowed.
